## Notes
- Test class: `IdTokenSignInTests` (in `BabeGetThisTests/Auth/IdToken/`) with at least `testNonceIsSha256Hashed` (the Android standard vector too), `testCancelIsNotAnError` and `testAppleFullNameIsSentAsUserMetadataName`. Add tests for the error mapping, the offline check and the not-configured case.
- AUTH-05 (Google):
  - Generate a random raw nonce and send its SHA-256 (lowercase hex) to Google (`GIDSignIn.sharedInstance.signIn(withPresenting:hint:additionalScopes:nonce:)`).
  - Pass the id token and the RAW nonce to Supabase `auth.signInWithIdToken(credentials: OpenIDConnectCredentials(provider: .google, idToken:, nonce: rawNonce))` through `AuthRemote`/`SupabaseAuthRepository`, on the one shared `SupabaseClient` in `AppContainer`.
  - Cancelling is not an error (the requester returns nil). Offline fails before the sheet opens (`NetworkMonitor`).
  - Failure shows "Google sign-in failed. Please try again." (Android's wording).
- Not configured (iOS only): if `GIDClientID` is empty or missing, don't call the SDK (it would crash). Return a failure that the login screen shows as "Google sign-in isn't set up in this build yet." Test it.
- AUTH-06 (Apple, an iOS addition for App Store rule 4.8):
  - Same nonce scheme. Use `ASAuthorizationAppleIDProvider` with the hashed nonce and scopes `.fullName` and `.email`, then `signInWithIdToken(provider: .apple, idToken:, nonce: rawNonce)` behind the same repository seam as Google.
  - On the FIRST authorisation Apple gives the full name. Send it as `user_metadata.name` (through the repository's existing name update) only when it isn't empty.
  - Cancelling (`ASAuthorizationError.canceled`) is not an error.
  - Put a "Sign in with Apple" button (`SignInWithAppleButton`, black or white per colour scheme) next to the Google button on the login screen, at the same prominence. A successful Apple sign-in behaves exactly like a successful Google one in `LoginViewModel`.
- Wiring:
  - Replace `GoogleSignInNotWired` in `AppContainer` with the real requester and repository.
  - Handle the Google redirect: `.onOpenURL { GIDSignIn.sharedInstance.handle($0) }` in `BabeGetThisApp`.
  - The requester needs a presenting view controller. Find the key window's root view controller at request time, on the main actor.
- Tests must not hit the network or show real sheets: put the SDKs behind small protocols and fake them.
- Keep the tests that already pass for `LoginViewModel` passing unchanged.
- Strings: no String Catalog yet. Use SwiftUI literals with Android's exact wording.
- Colours via `AppColors`, spacing via `AppMetrics`.
