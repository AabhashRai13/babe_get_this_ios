## Notes
- Test classes: `SyncTriggerTests` (at least 7) and `AppStartTests` with `testAuthIsRestoredBeforeTheFirstScreenDecision`.
- TRIG-01: `kick()` = `push()` then `catchUpAccount()`, on a detached task; results are discarded; no debounce, no timer; duplicate kicks are harmless. `pushSoon()` pushes without catching up: the trigger is the app's real `SyncKicking` (it replaces `NoOpSyncKicker` in both repositories).
- TRIG-02: a kick fires on an auth transition where `syncEngine.onAuthState(_:)` returns true (F29; this includes launch while signed in); on network becoming available, including at registration (`NetworkMonitor`); and on the app becoming active (scenePhase `.active`, once per foreground). Every auth state is handed to the engine, kick or not.
- APP-05: at app start, register the trigger and restore auth state before the first screen decision (Android also fetches feature flags; flags are out of v1).
- Wiring (you own `BabeGetThis/App/` in this run):
  - The sync stack exists already (F34): `container.syncEngine`, `container.sharedListRemote`, `container.shareRepository`, built lazily on one shared `SupabaseClient`. Keep those names and the laziness: test containers and `-sampleData` must not open a Supabase client or touch the network.
  - Replace `NoOpSyncKicker()` with the trigger for `ShoppingListRepository` and `ShoppingItemRepository`. The trigger reaches the engine lazily (for example through a closure) so building the container stays cheap.
  - Pass `catchUp: { try await <engine>.catchUp(listId: $0) }` to `ShoppingListRepository` (see the AppContainer comment and docs/PARITY.md DATA-06: without it, leaving an empty list that is on the server never deletes it). Remove the "F30 wires it" comments once done.
  - For `-sampleData` (signed-out guest, in-memory database) the trigger may be registered but must not reach the network; a guest has nothing to push.
- Don't edit files outside your owned paths. F35 (realtime, `Features/ListDetail/`) and F36 (adoption dialog, `Features/Lists/`) run in parallel and only read `AppContainer`'s frozen names.
- Tests must not hit the network: fake the engine behind a small protocol (push, catchUpAccount, onAuthState) and feed auth, network and lifecycle events by hand.
